# Jump to Start!

You are a robot (well a pair of robots). Unfortunatly, your manufacturing was botched, and neither of you can move much without breaking. But hey, maybe the power of friendship, and this cave, can help you repair yourself?

## Tech Stack
- Made fully in Godot!
- Game assets made using Aseprite

## How to run the project locally
(Make sure you have Godot installed beforehand)
(Also make sure to install "Godot Super - Wakatime" from the asset store)

1. Clone the repository locally
2. Open godot
3. Go to "Import" and select the folder of the projects root directory (should be called "HavenJumpstart")
4. Go to Project --> Project Settings --> Plugins, and enable "Godot Super - Wakatime"
5. Press F5, or the "Run Project" button. If all is well you should be able to play the game locally
